## 🚀 Featured projects

### 💰 [Financas](https://github.com/Se77ings/Financas)
Personal finance manager organized by billing period: income, expenses, credit card bills with installments, recurring payments, and a dashboard. I use it every month.

- C# / .NET API with a layered architecture, FluentValidation and the Result pattern
- Unit and integration tests with xUnit and in-memory SQLite

### 🛒 [OpenBox-Crawler](https://github.com/Se77ings/OpenBox-Crawler)
Aggregates "open box" deals from Brazilian computer stores into one searchable list, with price history to spot drops. The stores block automated access, so scraping runs in the user's browser through a **Chrome extension**, and the API only parses the captured HTML.

- pnpm monorepo with a layered backend (domain / application / infra)
- One HTML extractor per store behind a common interface

### ✅ [faz-ae](https://github.com/Se77ings/faz-ae)
Android to-do app with subtasks, deadlines, and **alarm-clock-style reminders**. The alarm library the app used (Notifee) was archived and doesn't support React Native's New Architecture, so I wrote my own Expo native module. It shows a full-screen alarm over the lock screen, loops the alarm sound, and offers Stop and Snooze buttons.
